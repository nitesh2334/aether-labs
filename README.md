# AETHER LABS

AETHER LABS is a futuristic AI-powered SaaS workspace built with modern full-stack technologies and a premium cyberpunk-inspired interface.

Designed as a high-end dashboard experience, the project combines clean frontend engineering, modular architecture, authentication systems, and scalable UI patterns inspired by products like Linear, Notion, and Vercel.

---

## Tech Stack

* Next.js 15
* React
* TypeScript
* Tailwind CSS
* Supabase
* Framer Motion
* Lucide Icons

---

## Features

* Premium futuristic dashboard UI
* Responsive sidebar + navigation system
* Authentication with Supabase Magic Links
* Modular component architecture
* Analytics dashboard
* AI Studio workspace
* Notes system
* Settings panel
* Dark luxury aesthetic
* Production-ready project structure

## Local Setup

```bash
git clone https://github.com/nitesh2334/aether-labs.git

cd aether-labs

npm install

npm run dev
```

---

## Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=your_project_url

NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
```
